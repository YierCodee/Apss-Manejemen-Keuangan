# Project: serkwu

## Tech stack

- Next.js 16.3.5 (App Router) with React 19.2.8
- TypeScript 5 with strict mode (`tsconfig.json`)
- Tailwind CSS v4 (`@import "tailwindcss"` in `app/globals.css`; **no** `tailwind.config.js`)
- ESLint v9 flat config (`eslint.config.mjs`)
- Path alias `@/*` → `./`

## Commands

```bash
npm run dev    # Next.js dev server (also regenerates .next/ and next-env.d.ts)
npm run build  # Production build
npm run start  # Start production server
npm run lint   # Run ESLint across the project
```

There is **no test framework** configured (no Jest/Vitest scripts in package.json).

## Key files

- `app/layout.tsx` — Root layout; imports Geist fonts and `globals.css`
- `app/page.tsx` — Home page
- `app/globals.css` — Tailwind v4 import + CSS variables for theming
- `next.config.ts` — Next.js config (currently empty, add options here)
- `tsconfig.json` — Strict TypeScript, includes `.next/types/**/*.ts`
- `next-env.d.ts` — **Auto-generated, do not edit** (managed by `next dev`)

## Conventions & gotchas

- **Tailwind v4** has no separate config file; customize via CSS `@theme inline` blocks in `globals.css`
- **ESLint v9** uses flat config (`eslint.config.mjs`), not `.eslintrc`
- `next-env.d.ts` is regenerated by `next dev` — never manually edit it
- Build artifacts (`.next/`, `out/`, `build/`) are gitignored
- Environment files (`.env*`) are gitignored
- The `public/` directory serves static assets (SVGs for the default template)

## Architecture

App Router pattern: `app/` directory maps to routes. Each folder can contain `page.tsx`, `layout.tsx`, `route.ts`, etc.
